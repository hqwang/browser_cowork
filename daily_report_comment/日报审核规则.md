# 日报审核规则

## 一、目标对齐
- **全局认知** 是否清楚自己的任务在整体目标中的位置
- **目标对齐** 今日工作是否指向阶段性目标，有无偏轨
- **主动澄清** 遇到目标模糊时是否主动澄清，而非自行假设
- **优先级** 优先级是否清晰，有无遗漏关键项
- **可执行性** 计划是否可执行、可量化，避免"继续推进"式表述
- **逻辑自洽** 是否与当前阻塞点挂钩，逻辑是否自洽

## 二、资源状况
- **资源匹配** 当前资源分配是否与任务优先级匹配
- **依赖管控** 依赖方是否已明确，等待时间是否可控
- **资源预警** 是否出现资源不足（人力、工具、预算）的信号
- **主动暴露** 资源瓶颈是否已提出，还是默默承压推进
- **上级协调** 是否有需要上级协调或跨团队支持的事项

## 三、组织与分工
- **责任归属** 任务是否落到具体责任人，有无"我们在做"式的模糊归属
- **分工清晰** 团队内部分工是否清晰，有无重叠或真空地带
- **负荷异常** 是否有人长期承压或长期低负荷的异常信号

## 四、流程执行
- **流程合规** 工作推进是否按既定流程走，有无随意跳步
- **风险暴露** 是否主动暴露了阻塞点，而非只报喜不报忧
- **风险定性** 风险是否有定性描述（影响范围、紧迫程度）
- **卡点反馈** 流程卡点是否被识别并反馈，还是被绕过或忽略
- **应对措施** 是否已有应对措施，还是仅停留在"发现问题"
- **系统修复** 是否有重复出现的流程问题，需要系统性修复

## 五、信息同步
- **描述具体** 描述是否具体？避免"推进中""对接中"等模糊表述
- **输出可查** 完成事项是否有可验证的输出物（文档、数据、链接等）
- **进度连贯** 进度与昨日日报是否连贯，有无跳跃或矛盾
- **同步到位** 关键信息是否已同步给相关方，有无信息孤岛
- **沟通闭环** 日报中是否出现"我以为对方知道"类的沟通断层
- **记录可溯** 重要决策、变更是否有书面记录可追溯

## 六、协同效率
- **协作顺畅** 跨团队协作是否顺畅，有无推诿或响应迟缓
- **阻塞升级** 协同阻塞是否已升级处理，还是停留在执行层自行消耗
- **管理介入** 是否需要管理者出面打通上下游关系
