## 一、飞书文档 DOM 的核心陷阱

### 1.1 虚拟滚动（Virtual Scrolling）

**现象**：`document.querySelectorAll('[data-block-id]')` 只能拿到视口附近已渲染的块；距离视口较远的块被替换为 `placeholder-wrapper-{id}` 空元素，`innerText` 为空。

**踩坑**：0507 日报有 5 名成员，第 5 位张晓宇（位置靠下）未被渲染，提取时缺失。

**解法（两阶段）**：
1. 从大纲（`.catalogue__list-item`）获取完整成员列表 —— 大纲是全量加载的，不受虚拟滚动影响
2. 逐个在大纲中点击成员行 → 等待对应 `heading3` 出现在 DOM → 再提取内容块

**关键代码模式**：
```python
# 先从大纲拿完整列表（不受虚拟滚动影响）
member_names = js(f'window.__getMembersForDate("{date}")')
# 再逐人导航触发渲染
for name in member_names:
    nav_click(js(f'window.__navToMember("{date}", "{name}")'))
    # 轮询等 heading3 出现
    for _ in range(16):
        wait(0.5)
        if find_heading_id(date, name): break
```

### 1.2 零宽字符（Zero-Width Characters）

飞书文档内容中大量混入零宽字符（`​‌‍﻿‎`），导致：
- 文本比较失败（`includes()` 返回 false）
- snippet 匹配不到 span

**必须在所有文本操作前统一 clean**：
```javascript
const ZERO = /[​‌‍﻿‎]/g;
const clean = t => (t || '').replace(ZERO, '').trim();
```

### 1.3 isTrusted 限制

飞书工具栏（划选文字后弹出的格式条）只响应 `isTrusted=true` 的真实鼠标事件，JS `dispatchEvent()` 合成事件无效。

**唯一解法**：用 CDP `Input.dispatchMouseEvent` 模拟真实鼠标拖选：
```python
def drag_select(x1, y, x2, steps=8):
    cdp("Input.dispatchMouseEvent", type="mousePressed",  x=x1, y=y, button="left", clickCount=1)
    for i in range(1, steps + 1):
        xi = round(x1 + (x2 - x1) * i / steps)
        cdp("Input.dispatchMouseEvent", type="mouseMoved", x=xi, y=y, button="left")
    cdp("Input.dispatchMouseEvent", type="mouseReleased", x=x2, y=y, button="left", clickCount=1)
```

**注意**：坐标必须来自 `getBoundingClientRect()`，在拖选前 `scrollIntoView` 确保目标在视口内。

### 1.4 execCommand 换行截断

`document.execCommand('insertText', false, text)` 在遇到 `\n` 时会截断，导致评论内容不完整。

**解法**：在 Python 侧和 JS 侧双重清理：
```python
# Python: 合并多行
text = " ".join(b["text"].splitlines()).strip()
```
```javascript
// JS: 替换换行
const safeText = commentText.replace(/[\r\n]+/g, ' ').trim();
```

### 1.5 getBoundingClientRect 坐标在视口外时为负值或超出

大纲列表过长时，部分条目超出屏幕范围，`getBoundingClientRect()` 返回的 `y` 超出视口高度，CDP 鼠标事件无效。

**解法**：取坐标前先 `scrollIntoView`：
```javascript
el.scrollIntoView({ behavior: 'instant', block: 'nearest' });
const r = el.getBoundingClientRect();
```

## 二、工具链经验

### 2.1 进程锁防重复执行

MCP timeout 时上一个进程仍在运行，第二次触发会启动第二个实例，导致重复提交。

**解法**：进程启动时写入 PID 文件，退出时删除：
```python
LOCK_FILE = Path("/tmp/feishu_submit.lock")
# 启动时检查 + 写入
# 退出时 unlink(missing_ok=True)
# finally 块确保释放
```

### 2.2 browser-harness 执行 JS 的注意事项

- **执行 JS 本身会导致飞书失焦**，工具栏会消失 → 不能在拖选后用 JS 点评论按钮，必须用 MutationObserver 提前挂钩子
- **JS eval 返回值**是通过 CDP 序列化的，`undefined`、`NaN` 等特殊值会变成 `null`
- **大块 JS 注入**建议写在独立 `.js` 文件中，`read_text()` 读取后 `js(code)` 执行，便于调试和版本管理

### 2.3 MutationObserver 替代 JS click

用 `MutationObserver` 监听 DOM 变化，在工具栏出现的瞬间自动点击评论按钮：
```javascript
window.__armCommentObserver = function() {
  const obs = new MutationObserver(mutations => {
    for (const m of mutations) {
      for (const node of m.addedNodes) {
        const btn = node.querySelector?.('.comment-item');
        if (btn) { btn.click(); obs.disconnect(); return; }
      }
    }
  });
  obs.observe(document.body, { childList: true, subtree: true });
  // 必须在 CDP drag_select 之前调用！
};
```

## 三、架构设计经验

### 3.1 不要硬编码坐标

飞书布局随窗口大小、系统缩放、浏览器版本变化。坐标只能来自：
- `getBoundingClientRect()` 动态计算
- 封装好的定位函数（如 `__navToMember`）

硬编码 `click_at_xy(26, 94)` 等数字在换机器或调整窗口后立刻失效。

### 3.2 大纲是虚拟滚动的救星

`.catalogue__list-item` 是飞书大纲的列表条目，全量加载、不受虚拟滚动影响。
对于"需要遍历所有成员"的场景，**永远从大纲获取列表，而非从文档 DOM**。

### 3.3 两阶段内容提取

```
阶段1（枚举）：大纲 → 完整成员名单
阶段2（渲染）：逐人导航 → 触发 DOM 渲染 → 提取内容
```

不要试图一次性提取所有人的内容，因为虚拟滚动保证了不可能同时渲染所有人。

### 3.4 审核规则与脚本分离

不要在脚本中硬编码规则字符串。用 Markdown 文件存储规则，运行时解析：
- 规则可以独立更新，不需要改脚本
- 解析逻辑简单（几行正则），不引入新依赖
- 方便 PM 直接编辑规则文件

### 3.5 comment 生成不需要 LLM（对于规则型场景）

最终方案使用随机采样 + 规则拼接，每次从 7 个维度各随机抽 1 条子项，不调用 LLM：
- 零延迟，无 API 费用
- 结果可预期、可审计
- 多样性来自规则库本身，32 条子项已足够覆盖

## 五、踩坑时间线

| 问题 | 根因 | 解法 |
|------|------|------|
| 评论内容被截断 | execCommand 遇 `\n` 停止 | 提交前清理换行符 |
| 脚本执行了两遍 | MCP timeout 未杀进程，第二次重复启动 | 进程锁 `/tmp/feishu_submit.lock` |
| 0509 block not_found | 虚拟滚动卸载了远离视口的块 | 提交前重新导航到目标成员 |
| 大纲坐标无效 | 大纲条目超出屏幕，`getBoundingClientRect` y 超出视口 | 取坐标前 `scrollIntoView` |
| 审核规则硬编码 | 直接写在 `_REVIEW_RULES = {...}` 中 | 改为解析 `日报审核规则.md` |
| comment 带序号前缀 | 格式字符串加了 `➊ [维度名]` | 只输出问题本体，不加任何前缀 |
| 张晓宇缺失 | 位于列表第 5 位，初始视口未渲染，DOM 中是 placeholder | 从大纲获取完整名单，逐人导航 |
| 孙聪缺失 comment | 有 back_ref_list 块但被过滤，未走空报 fallback | 过滤后检查 member_rows 是否为空，空则走 heading_id fallback |
